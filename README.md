# Growth Audit — Hushed

**Live:** https://bterzic123.github.io/hushed-flow-rebuild/

Five ideas to unlock more revenue from the traffic Hushed already has, each one built into a clickable prototype of the onboarding and paywall in Hushed's own design. Prepared by Adapty, October 2026.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Show the number before the sign-up | CR +8% · ARPU +17% |
| 02 | Give Skip a real second option (your 30 Day prepaid plan, 8,99 €) | ARPU +10–15% |
| 03 | Put their reason in the paywall headline | CR +15–20% |
| 04 | Put 4.6 stars and 25 million downloads on the paywall | CR +10–15% |
| 05 | Ask about tracking after the purchase | CR +10–15% |

Open the prototype on a phone with `?open=proto`. It runs full-screen, in English, French or Spanish, light or dark, and has a 30-second walkthrough.

**Grounding.** Every price, rating, quote and feature line comes from Hushed's own App Store listing, hushed.com and in-app screens. The phone number shown is a reserved demo number.

*Impact ranges are Adapty's expected effect from teardowns and A/B tests across subscription apps — not measured lift for Hushed.*

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
